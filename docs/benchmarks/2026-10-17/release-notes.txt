首个原生 Apple Silicon 预览版，macOS 13+。

- USB MTP 文件浏览、上传/下载文件和文件夹，显示 USB 协商速度、进度与 MB/s。
- USB 3 SuperSpeed 大块传输路径及 16 KiB 兼容模式。
- 内置官方 arm64 ADB / Fastboot 37.0.1：ADB Shell、交互终端、重启到 Recovery / Bootloader / fastbootd、选择镜像并刷入指定分区。
- 命令绑定所选设备并显示完整命令供确认。

本机验证：macOS 27.2 开发版上编译并成功启动；12 个捆绑 Mach-O 均为 arm64；签名、动态库路径、参数与路径安全测试通过；ADB/Fastboot 版本检查及 MTP 无设备探测通过。

预览限制：已于 2026-10-17 完成下述单设备 1 GiB 实机传输及应用内 ADB Shell 验证。其他机型、>4 GiB、拔线/取消及 Fastboot 刷机操作尚未验证；macOS 28 尚未发布。采用 ad-hoc 签名，尚未 Developer ID 公证。

下载 Android-File-Transfer-Mac-ARM.zip 后解压，将 .app 拖入应用程序。Sources.zip 含应用源码、构建脚本与 LGPL 库对应源码；SHA256SUMS.txt 可校验文件。

这是独立开源替代应用，与 Google 旧版 Android File Transfer 无隶属关系。macOS 无需另装 Windows OEM ADB 驱动。使用方法和注意事项见 README。

## 实机测试补充（2026-10-17）

Xiaomi 15 Ultra（25019PNF3C），Android 16；经 USB 3 Hub，系统报告协商链路
**10 Gbps**。样本为 **1 GiB（1,073,741,824 字节）**，测试数据位于手机下载目录
的专用子目录。下表 MB/s 均采用十进制单位。

| 测试 | 结果 | 测量范围 |
|---|---:|---|
| USB MTP 上传：Mac → 手机 | **577.27 MB/s** | 单次 1 GiB，1.860 秒 |
| USB MTP 下载：手机 → Mac | **437.72 MB/s** | 单次 1 GiB，2.453 秒 |
| 手机内部顺序读取 | 631.77 MB/s | 1 MiB 块，下载目录文件系统 |
| 手机内部顺序写入 | 259.45 MB/s | 1 MiB 块，包含末尾 fsync |
| 手机内部 4 KiB 随机读取 | 944.95 MB/s，230,701 IOPS | Q1T1，**缓存影响无法排除** |
| 手机内部 4 KiB 随机同步写入 | **79.29 MB/s，19,359 IOPS** | Q1T1，O_DSYNC |

**校验通过：**原始文件、手机文件、下载副本的 SHA-256 完全一致。
应用内 ADB 刷新与 `adb shell getprop ro.product.model` 也已通过，返回型号
`25019PNF3C`，退出码 0。

MTP 数据来自使用发布版同一 C 桥接代码与动态库的测试程序，未覆盖 GUI 的全部
传输交互。这是单设备、单次短样本，不能外推到所有手机或长时间持续吞吐。
手机内部读写与 USB 传输分开测量；下载目录经过 Android emulated storage/FUSE，
即使调用者保留 O_DIRECT，也不能证明底层完全绕过缓存，**不将 4K 读取结果
作为 UFS 裸性能结论**。
